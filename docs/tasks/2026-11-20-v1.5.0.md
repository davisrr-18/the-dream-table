## Objective

1. **In-game feedback form** on the Settings tab (Options page). The text goes to a Cloudflare Worker, which writes each submission into the user's vault (Rede Neural), in a new **feedback** area inside the The Dream Table project. Only technical data is sent: text, category (bug, idea, other), mod version, loader, Minecraft version. Nothing that identifies the player.
2. **How It Works on My Schematics**: help text on where to save schematic files, which formats and size are read, how schematics work on a server, and why a file shows greyed out.
3. **Audit fixes (2026-11-06, confirmed by reading)**: ChunkKeeper skips the ticket of the first loaded chunk; the placement preview erases a finished farm's record; discarding a build without a farm neither dismantles nor warns; scheme button IDs collide with material swaps above 800 schemes. Each one is reproduced by a test before the fix.
4. **Page 21 hypothesis**: `TableSession.REMOVED_ALERTS_PAGE` and `DreamTableScreenHandler.PAGE_FARM_INFO` are both 21. Confirm by test, then fix.
5. **Minecraft 1.21.11 port** on a new branch `mc/1.21.11`, carrying 1.5.0, as its own final milestone.

Items 1 to 4 also go to `mc/1.20.1` by cherry-pick, as in 1.4.0.

## Milestone 1 findings

- **ChunkKeeper** (`farm/ChunkKeeper.java:44-45`): default `Long.MIN_VALUE` makes `now - last` overflow negative, so the first `keepSpot` of an already loaded chunk returns without a ticket. Fix: default `now - RENEW_TICKS`. Memory only, no NBT.
- **Preview erases finished farm** (`farm/FarmAreas.java:402-406` in `conflict`, reached from `CheckPlacementPayload` via `SessionAreas`). `forgotten` (`:551-557`) removes a finished farm without layout or under 50% loaded. Fix: `conflict` skips it without removing; `find` uses the same rule.
- **Discard without farm** (`block/entity/TableSession.java:665`): `template != null` gate has no else; reset at `:690-698` runs anyway. Fix: send `discard_changed` when `takeApart` and the template is gone.
- **Button IDs** (`screen/TableButtons.java:80-86`; `SchemesPage.java:67`; `ServerSchematicsPayload.java:35`, cap 1024). Fix: cap at `BUTTON_SWAP_OPEN - BUTTON_SCHEME` (800) with a notice; protocol 4 to 5.
- **Page 21** (`TableSession.java:51-52`, `:885-891`; `DreamTableScreenHandler.java:44`): Farm Info is persisted as 21 and read back as the removed Alerts page, so it reopens on My Farms. Fix: `write()` saves `PAGE_WORK` for Farm Info through a static `savedPage(int)`; ids unchanged. Residue: sessions saved on 21 before the fix reopen on My Farms once.
- **Schematics help**: a small new page (id 22, button 112) that reuses `FarmInfoText.layout`; facts from `ImportedStructures.java:77-119`, `SchematicReader.java:34-44`, `ImportNote.java:26-50`. The code also reads `config/litematica` and `config/the_dream_table/structures`, and reads the world folder before the latter; the README must match the code.
- **Feedback form**: only `SearchBox` uses a `TextFieldWidget`. `DreamTableScreen.keyPressed` (`:267-313`) runs R/M hologram keys before any focus check and ESC closes Options; the feedback field needs the search gate (`:268-270`). No HTTP or client executor exists; Java 21 `HttpClient` with `sendAsync`, result back on the client thread, shown with `TableNotices`. Version: Fabric has it (`FabricHandshake.java:120-124`), NeoForge/Forge need a per-loader accessor. Lang keys go into `en_us.json` and `pt_br.json` (`LangParityTest`).
