## Objective

Ship 1.3.0 on more platforms: Forge on Minecraft 1.21.1 (next to Fabric and NeoForge), and Minecraft 1.20.1 on Fabric and Forge.

## Acceptance criteria

- [ ] `main` (MC 1.21.1) builds Fabric, NeoForge and Forge jars into `build/release/<loader>/`; `./gradlew build` green.
- [ ] Branch `mc/1.20.1` builds Fabric and Forge jars for MC 1.20.1 (Java 17); `./gradlew build` green.
- [ ] Same features on every loader and version; dedicated-server smokes by the user per loader.
- [ ] CHANGELOG.md describes 1.3.0.

## Scope

- In: `forge` module on `main`; port of all of `common` plus Fabric and Forge modules to 1.20.1 on `mc/1.20.1`.
- Out: NeoForge on 1.20.1; Minecraft 1.21.11 (later, own branch `mc/1.21.11`); new gameplay features; release (only after the user says they will post it).

### Milestone 1 results (2026-11-05)

Agents actually run (Sonnet, read-only on the repo): toolchain (general-purpose, with throwaway builds in the session
scratchpad), server-side diffs (investigator), client/resources diffs (investigator). Code findings come from reading,
not compiling against 1.20.1; the orchestrator did not re-verify them, the compiler will in Milestone 2.

**Toolchain (verified by throwaway builds):**
- Loom 1.17.493 + Gradle 9.4.1 build a Forge 1.21.1-52.1.21 module with plain Yarn 1.21.1+build.3 (no forge patch exists for
  1.21.1); jar remapped to Mojmap. Needs `loom.mixin.useLegacyMixinAp = false`, `loom.platform=forge` in `forge/gradle.properties`,
  maven.minecraftforge.net, `META-INF/mods.toml` (`loaderVersion="[52,)"`). Three platforms together not built yet.
- Same Loom/Gradle build Forge 1.20.1-47.4.28 + Yarn 1.20.1+build.10 with `release = 17` on JDK 21. Only JDK 21/25 installed;
  dev client on Forge 47 under Java 21 not tried.
- Risk: Forge-only names may be missing from plain Yarn once the real adapters are written.

**Forge adapters on 1.21.1 (M):** most NeoForge seams have direct Forge 52 events (`BlockEvent`, `TickEvent.*.Post`,
`RenderGuiEvent.Post`, `RenderLevelStageEvent`, `DeferredRegister`, `IForgeMenuType`, `FMLPaths`). Real design work:
networking (`ChannelBuilder` ... `payloadChannel()`, int protocol version vs our String `NetworkProtocol.VERSION`, `canSend` ->
`isRemotePresent`), menus (wrap `FriendlyByteBuf` in `RegistryFriendlyByteBuf`), screens registered in `FMLClientSetupEvent`,
world render gives a `Matrix4f` instead of a `MatrixStack`.

**1.20.1 port of common (about 4-5 days of work):**
- Network (largest): about 25 payload types on `CustomPayload`/`PacketCodec`/`RegistryByteBuf` (1.20.5+), `TextCodecs`, bounded
  `toList(MAX)` caps (security: keep the caps by hand), `OpenData` screen-opening codec, `platform/ServerNetwork`,
  `ClientNetwork`, `Menus` seams. 1.20.1: own payload interface on `PacketByteBuf`; Fabric `ServerPlayNetworking`, Forge 47
  `SimpleChannel` + `NetworkHooks.openScreen`. Fabric network tests (about 25 test files) change with it.
- Persistence: `BlockEntity` NBT without `WrapperLookup` (12 sites), `PersistentState` `Type` -> `getOrCreate(reader, supplier, id)`
  (5 classes). State ids and NBT keys stay the same. Saved designs/parked projects embed item NBT, so they do not move between
  Minecraft versions (worlds of one version only).
- Blocks: `DreamTableBlock` codec, `onUse` signature, `validateTicker`, override visibility; `Blocks.TRIAL_SPAWNER`/`VAULT` in `StepCollector`.
- Data components: `MaterialLedger.plain` (`hasNbt`), container lock and loot table checks in `NearbyContainers`.
- `SchematicReader` uses the 1.20.2+ `NbtSizeTracker` API; the size-limit path needs a rewrite.
- Client render: `GhostRenderer`/`ClipboardDraw` buffer API (`getBuffer`/`begin`/`.next()`/`end()`), riskiest, visual-only check.
- Screens: `mouseScrolled` 3 args, `renderBackground(DrawContext)`, `renderButton`, `MapCameraEntity` data tracker/eye height.
- `Identifier.of` -> `new Identifier` (about 30); Java 21 calls `getFirst`/`getLast`/`Math.clamp` (6).
- Resources: `recipe`->`recipes` (result `item`), `loot_table`->`loot_tables`, `tags/block`->`tags/blocks`; Forge needs `pack.mcmeta`
  (format 15). The 11 bundled `.schem` were saved on 1.21.1: block-entity item NBT inside them may not read on 1.20.1 (unverified, check first).
